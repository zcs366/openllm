## 详细数据

### M1 记忆保持率（30天后）
```
imp=9.0 insight     temp=10.00 ✅ 保持（深刻教训）
imp=7.0 preference  temp= 8.49 ✅ 保持（用户偏好）
imp=5.0 event       temp= 1.28 ✅ 边缘保持
imp=3.0 noise       temp= 0.09 ❌ 遗忘（噪声）
```
**洞察**：噪声被正确遗忘，深刻教训被正确保持——"选择性遗忘"不是口号，是测量结果。

### M2 遗忘曲线（指数衰减形状）
```
insight(λ=0.01): [5.10, 4.76, 3.80, 2.13]  90天衰减 58.2%
noise(λ=0.5):    [5.10, 0.25, 0.10, 0.10]  30天衰减 98.0%
```
**洞察**：单调递减 + 选择性（insight 90 天衰减远慢于 noise 30 天）——牛顿冷却引擎的行为与理论一致。
**v0.1 判据修正记录**：初版用"insight 90天衰减<50%"绝对阈值，数学上不成立（e^-0.9≈0.41 即 59%）；改为相对判据"noise 衰减 > insight×1.5"验证选择性——判据问题非引擎问题。

## 方法论说明

- **为什么不用 SWE-bench/Terminal-Bench**：qwen3.5:9b 本地模型跑 GAIA/TB 远超能力，选错基准=公开丢脸（赫淮斯托斯裁决）
- **为什么自建度量**：度量"记忆-治理-身份"三角是 openLLM 独有能力，现有基准无一覆盖；可复现数字>不可比较的分数
- **可复现性**：单脚本零依赖外部服务，任何机器 `python benchmarks/jushen_metrics.py` 可重跑
- **下一步**：M5 工具调用成功率（function calling 链路，2026-08-31 刚接通）、M6 治理仲裁（五级仲裁触发率）——随 G-1 治理通电后补充
