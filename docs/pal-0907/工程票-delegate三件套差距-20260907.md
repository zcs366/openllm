## 一、差距判词（一句话）

Hermes 现状 delegate_task = **"一次性派发+摘要回传"**；前沿已实现 **"目标+工具集+loop" 三件套**——子 agent 拿到的是使命不是任务书，是工具箱不是空手，是循环不是单发。三件套差距逐条列票。

## 二、票表

| # | 票 | 内容 | 前沿参照 | 优先级 |
|---|---|---|---|---|
| T1 | **目标语义升级** | 派发物从"指令清单"升级为"目标+边界+验收判据"三段式：目标（为什么）/边界（不准碰什么）/验收（军师怎么查） | Anthropic orchestrator-worker：worker 拿 research objective 而非 step list | P0 |
| T2 | **工具集声明** | 派发时可指定子 agent 可用工具白名单（最小授权 per task），回传必须带"用了哪些工具"的 trace | Claude Code subagents 独立工具集+worktree 隔离 | P0 |
| T3 | **loop 授权** | 派发物带循环预算（max iterations / 停止条件），子 agent 在预算内自主迭代而非一次往返 | OpenAI Agents SDK handoffs + loop budget | P1 |
| T4 | **只读/写分类器** | 子 agent 任务自动分类：只读类（研究/分析/评估）→ 并行安全；写类（改文件/发布）→ 单线程串行 | Cognition：只读 subagent≈工具调用，写操作保持单线程 | P0 |
| T5 | **完整对话传递选项** | handoff 模式：除"隔离上下文"外增加"传递完整对话"模式（上下文继承型委派） | OpenAI SDK handoff 传完整对话历史 | P2 |
| T6 | **联邦生命周期** | 主 SA 成立联邦（多子 agent 共享总线/互见），主 SA 结束联邦即解体——瞬态自创生完整周期 | FoA Versioned Capability Vectors（素材-4）；Hermes 无现成实现，openLLM EventBus 是底座 | P1 |
| T7 | **回传结构化下界** | 回传必须≥N bits 结构化结果（判决+证据+文件路径），拒绝"说做完了" | 军师终裁定理3判决标准1（主上下文验收信息量下界） | P0 |

## 三、耦合关系

- T1/T2/T7 = **一次派发协议升级**（改 delegate payload schema，一起做）
- T4 = 派发前路由判断（与路由学科合流：任务→工程形态匹配的第一个落地件）
- T6 = 依赖 EventBus（openllm/src/openllm/iai/event_bus.py 已有），联邦=总线订阅组+租约
- 三件套全部就位后，ZA 试验场（za_runner）可从"外挂脚本"升级为"原生器官"

## 四、验收判据（军规）

- 每票交付须带：schema 变更 diff + 1 条端到端测试（真派发一个子 agent 走通新字段）+ 向后兼容断言（旧格式派发不炸）
- T4 验收：构造只读/写混合任务组，断言写任务串行执行且只读并行
- T6 验收：联邦成立→互见→主 SA 结束→总线订阅自动清理，全程事件可审计
