## 一、这是什么

把 ISA 通信体战役的四条腿组装成 **agent 可直接使用的通信栈**：

| 腿 | 模块 | 职责 |
|---|---|---|
| P0-2 语义路由 | `iai/event_semantic.py` | 传得准——广播按兴趣找人 |
| P0-1 裁决模块 | `governance/adjudication.py` | 该不该传——L0 硬规则/L1 评分/L2 打扰治理 |
| P1-3 可靠会话 | `iai/session.py` | 传得稳——ACK/超时/重试状态机 |
| P1-4 温度脉冲 | `iko/pulse.py` | 温度——非任务主动振动 |

**一句话**：任意 agent 注册进 Registry 后，就能 `send/reply/broadcast` 可靠通信——
裁决把关（该不该）、语义路由定向（给谁）、会话追踪（稳不稳）、事件可见（谁知道）。

## 二、快速上手（30 秒）

```python
from openllm.comm import Registry, CommAgent
from openllm.iai.session import SessionManager
from openllm.iai.event_bus import EventBus
from openllm.governance.adjudication import TransmissionAdjudicator

# 1. 基础设施（共享！会话必须同一状态机）
sessions = SessionManager(sessions_dir=Path("~/.openllm/comm/sessions").expanduser())
bus = EventBus()                      # 可选：事件可见性
adj = TransmissionAdjudicator()       # 可选：裁决（该不该传）
reg = Registry(sessions=sessions, bus=bus, adjudicator=adj)

# 2. agent 注册 + 声明兴趣
a = CommAgent("IAI", registry=reg, interests=["模型训练"])
b = CommAgent("ISN", registry=reg)
b.on_message(lambda agent, msg: f"收到：{msg.body}")   # 返回 str = 自动回复

# 3. 通信
r = a.send("ISN", "查一下语义路由技能", kind="ask")    # ask 期待回复
b.run_once()    # ISN 收：auto-ACK → handler → 自动 reply
a.run_once()    # IAI 收 reply → 发起方自动 close 会话

# 4. 广播找人（只发给兴趣匹配者）
a.broadcast("模型训练进展……", semantic=True)
```

## 三、核心概念

### CommMessage（消息信封）
`msg_id / from_id / to_id / kind(tell|ask|reply|notify|broadcast) / body /
importance / urgency / session_id / reply_to`

### 可靠会话生命周期
```
A.send(ask) → session INITIATED → B.run_once ACKED → handler 回复
            → B reply → RESPONDED → A 收 reply → CLOSED（发起方自动闭环）
超时 → 重试(≤3) → ESCALATED（A.check_timeouts() 触发 watchdog）
```

### 裁决双闸门（P0-1）
- **send 闸门**：发之前裁决（黑名单/红线/频控/凭据）
- **deliver 闸门**：收之前裁决（收方被打扰的频控）
- **L2 打扰治理**：`adj.set_daily_budget("某人", 2)`——打扰型（wake/pulse）
  每日额度 + 互唤振荡冷却。正常 comm.ask/reply 完全不受影响。

### 广播语义路由（P0-2）
`broadcast(body, semantic=True)`：对所有 agent 的兴趣做 embedding 匹配
（bge-small-zh 中文）；引擎不可用时自动降级关键词。**命中才发**——不打扰无关者。

## 四、接入新 agent 的配方（五步）

1. **起身份**：`agent = CommAgent("你的名字", registry=reg)`——名字唯一，重复注册会报错
2. **声明关心**：`agent.register_interest("语义路由")`——broadcast 路由靠它
3. **定义接收**：`agent.on_message(handler)`——handler(agent, msg) 返回 str 自动回复
4. **驱动心跳**：定期 `agent.run_once()`（收消息）+ `agent.check_timeouts()`（超时 watchdog）
   ——进程内可起线程；多进程/壳场景 v1 用队列适配器
5. **查统计**：`agent.stats()` / `sessions.get_stats()` / bus 事件订阅

## 五、温度脉冲（军师想到你）

```python
from openllm.iko.pulse import PulseEngine, TimeWindow
pulse = PulseEngine(recipient="张成市", adjudicator=adj,   # 共用裁决器=共用打扰预算
                    time_window=TimeWindow(9, 22),          # 只在 9-22 点振
                    context={"context": "裁决模块"})         # context 用名词短语
pulse.tick()   # 心跳调用；到点+过裁决 → 投递一条温度脉冲
```
三原则：稀有才珍贵（日硬顶 3）/ 非任务驱动（纯温度）/ 裁决先行（打扰预算管住）。

## 六、架构总览

```
                    ┌─────────────────────────────────┐
                    │         Registry（寻址）          │
   CommAgent A ─────┤  agent_id → CommAgent（mailbox） │───── CommAgent B
   send/reply/      └───────────────┬─────────────────┘     on_message
   broadcast                        │
        │            裁决(该不该)    │       裁决(该不该收)
        ▼              ▲            ▼            ▲
   TransmissionAdjudicator    SessionManager（ACK/超时/重试）
   (L0硬规则/L1评分/L2打扰)     EventBus（comm.* 事件·全程可见）
        │
        └── 温度：PulseEngine（IKO）──→ 用户（稀有/非任务/过裁决）
```
