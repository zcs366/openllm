# ITA 编码的 MDL 最优向量维度分析

> **版本**：v1.0 · 2026-05-27
> **性质**：理论推导文档
> **前置**：T-IAT-01（Kolmogorov↔Bekenstein 桥接）

## 一、引言：MDL 原则

**最小描述长度原则（MDL）**：最好的模型是总描述长度最短的模型。

$$\text{MDL} = L(\text{模型}) + L(\text{数据}|\text{模型})$$

在 ITA 中：
- **模型** = 编码器/解码器（复杂度随维度 d 增加）
- **数据** = 代码行为的编码（长度随维度 d 减少）
- **最优维度** d* = argmin(总描述长度)

---

## 二、ITA 的 MDL 框架

### 2.1 模型复杂度 M(d)

编码器将代码映射到 d 维向量。编码器的复杂度由以下因素决定：

1. **参数数量**：编码器的参数量 ∝ d × input_dim
2. **量化级别**：FSQ 将连续向量量化为 L 个离散级别
3. **描述长度**：

$$M(d) = d \cdot \log_2 L + C_{\text{arch}}$$

其中：
- $d$ = 编码维度
- $L$ = FSQ 量化级别数
- $C_{\text{arch}}$ = 架构固定开销（与 d 无关）

**物理类比**：M(d) 对应黑洞的"视界面积"——描述黑洞本身需要多少信息。

### 2.2 数据编码长度 D(d)

给定编码维度 d，代码行为的编码长度：

$$D(d) = H_s(C) - I(f(c); \text{exec}(c))$$

其中：
- $H_s(C)$ = 语义熵（代码空间的固有信息量）
- $I(f(c); \text{exec}(c))$ = 编码向量与执行行为之间的互信息

**关键关系**：互信息 I 随 d 增加而增加（编码越精确，保留的信息越多），所以 D(d) 随 d 增加而减少。

**物理类比**：D(d) 对应黑洞的"内部自由度"——黑洞内部有多少信息。

### 2.3 总描述长度

$$\text{MDL}(d) = M(d) + D(d) = d \cdot \log_2 L + C_{\text{arch}} + H_s(C) - I(d)$$

其中 I(d) 是维度 d 下的互信息。

## 三、最优维度 d* 的推导

### 3.1 互信息的近似

由信息瓶颈理论（Tishby et al., 1999），互信息 I(d) 满足：

$$I(d) \leq d \cdot \log_2 L$$

（FSQ 的容量上限：d 维、L 级量化的最大信息量）

实际中，I(d) 通常呈饱和曲线：

$$I(d) \approx I_{\max} \cdot (1 - e^{-d/d_0})$$

其中 $I_{\max}$ 是最大可提取信息量，$d_0$ 是特征尺度。

### 3.2 最优维度

对 MDL(d) 求导：

$$\frac{d(\text{MDL})}{dd} = \log_2 L - \frac{dI}{dd}$$

设导数为零：

$$\log_2 L = \frac{dI}{dd}$$

代入 I(d) 的近似：

$$\log_2 L = \frac{I_{\max}}{d_0} \cdot e^{-d^*/d_0}$$

解得：

$$d^* = d_0 \cdot \ln\left(\frac{I_{\max}}{d_0 \cdot \log_2 L}\right)$$

### 3.3 物理含义

| ITA 量 | 物理对应 | 含义 |
|--------|---------|------|
| $d^*$ | 临界面积 $A_c$ | 信息存活的临界维度/面积 |
| $I_{\max}$ | 黑洞最大熵 | 系统能存储的最大信息量 |
| $d_0$ | 普朗克面积 $l_P^2$ | 信息的基本单元 |
| $\log_2 L$ | 量子态数 | 每个自由度的信息容量 |

## 四、与 Kolmogorov 下界的关系

T-IAT-01 推导了 Kolmogorov 下界：

$$K_s(c) \geq H_s(C) - O(\log H_s(C))$$

MDL 给出了**最优权衡点**：

- **Kolmogorov 下界**：压缩的终极极限（理论下界）
- **MDL 最优点**：在给定编码器复杂度下的最优压缩（工程上界）

两者的关系：

$$H_s(C) \leq K_s(c) \leq \text{MDL}(d^*)$$

**Kolmogorov 是理想，MDL 是现实。**

## 五、与黑洞物理的对应

### 5.1 黑洞的 MDL

在黑洞物理中，MDL 原则的对应：

- **模型** = 黑洞本身（由质量 M、电荷 Q、自旋 J 描述）
- **数据** = 黑洞内部的信息
- **视界面积** A = 模型复杂度（描述黑洞需要多少信息）
- **内部自由度** = 数据复杂度（黑洞内部有多少信息）

黑洞的"最优压缩"：当内部信息全部编码在视界上时，达到 Bekenstein-Hawking 熵。

### 5.2 对应表

| ITA | 黑洞物理 | 数学结构 |
|-----|---------|---------|
| $M(d) = d \cdot \log_2 L$ | $S_{\text{horizon}} = A / (4 l_P^2)$ | 模型复杂度 ∝ 面积/维度 |
| $D(d) = H_s(C) - I(d)$ | $S_{\text{interior}} - S_{\text{horizon}}$ | 数据复杂度 = 总信息 - 已编码信息 |
| $d^* = d_0 \cdot \ln(I_{\max}/d_0 \log_2 L)$ | $A^* = 4 l_P^2 \cdot S_{\text{BH}}$ | 最优压缩的临界点 |
| $\text{MDL}(d^*)$ | $S_{\text{BH}}$ | 最优总描述长度 |

### 5.3 关键洞见

**黑洞是最优 MDL 压缩体。**

黑洞的视界面积恰好编码了内部所有信息（Bekenstein-Hawking 熵），没有冗余，没有不足。这正是 MDL 原则的物理实现：模型（视界）+ 数据（内部）达到最优平衡。

**ITA 的最优维度 d* 对应黑洞的临界面积 A*。**

当编码维度 d < d* 时，信息丢失（类似黑洞蒸发时信息丢失）。
当编码维度 d > d* 时，冗余增加（类似黑洞吸积时面积增加）。
当 d = d* 时，达到最优压缩（类似稳定黑洞）。

## 六、实验验证方案

### 6.1 维度消融实验

1. 固定编码器架构，改变维度 d = 1, 2, 4, 8, 16, 32, 64, 128, 256
2. 测量每个维度下的：
   - 执行等价率 RTCE(d)
   - 编码器参数量 M(d)
   - 互信息 I(d)（通过编码向量与执行行为的相关性估计）
3. 计算 MDL(d) = M(d) + H_s(C) - I(d)
4. 找到 d* = argmin(MDL(d))

### 6.2 预期结果

- **低维区 (d < d*)**：RTCE 低，信息丢失严重
- **最优区 (d ≈ d*)**：RTCE 达到峰值，MDL 最小
- **高维区 (d > d*)**：RTCE 不再提升，MDL 增加（冗余）

### 6.3 与 Page curve 的对应

维度消融曲线的形状应该类似 Page curve：
- 早期（d 增加）：RTCE 上升（信息开始被编码）
- 临界点（d = d*）：RTCE 达到峰值（信息完全编码）
- 后期（d 继续增加）：RTCE 饱和（冗余增加）

**这就是 ITA 版的 Page curve。**
